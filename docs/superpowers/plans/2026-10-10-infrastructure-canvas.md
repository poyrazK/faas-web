# Infrastructure Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an owner-local, flag-gated `/dashboard/canvas` page. It draws the whole account as a node graph (Internet → domains → apps → buckets / Postgres, with crons feeding apps). Each node has a docked detail panel, and "+" connectors create domains, crons and buckets inline.

**Architecture:**

- **Pure functions** turn existing `/v1` reads into a typed `Topology`, then into positions (`layout`) and edge traffic (`traffic`). All edges come from IDs.
- **React Flow** (`@xyflow/react`) does only pan, zoom, selection and handles. Every node, edge, menu and panel is a Gregale component in the Wind visual language, built from `index.css` tokens.
- **Gating:** one build-time flag gates the nav entry and the route. The route loads the page through a dynamic `import()` behind the literal flag, so the whole feature (CSS included) folds out of any build without it.

**Tech Stack:** React 19, TanStack Router (file routes, `autoCodeSplitting`), TanStack Query 5, `@xyflow/react` 12, Tailwind 4 tokens in `src/index.css`, `motion`, `iconoir-react`, Radix Popover (`radix-ui`), Vitest + React Testing Library, the Vite mock (`npm run dev:mock`).

**Spec:** `docs/superpowers/specs/2026-10-10-infrastructure-canvas-design.md`

## Global Constraints

**Gating and deploys**

- **Flag:** `featureFlags.canvas = enabled(import.meta.env.VITE_FEATURE_CANVAS)`, read only through `src/lib/feature-flags.ts`, with literal access so it folds.
- **Where the flag is on:** only the owner's `.env.local` (`.env*` is gitignored). Never set it on Vercel Preview or Production, and never push without asking.
- **Merge:** the work merges to `main` with the flag off.

**Spec prerequisite (fallback taken)**

- The spec's API refresh is **not** part of this plan; see Deferred.
- On 2026-10-10, `npm run api:pull` grew the spec from 371 to 1,116 operations and broke type-checking with 83 errors across 25 files. Several are real contract changes in unrelated features (alert `action`, cron `command_shell`, webhook rotation bodies, the removed invitation DELETE).
- v1 therefore uses only operations already in `api/openapi.yaml`. Never hand-edit `api/openapi.yaml` or `src/lib/api/schema.d.ts`.

**Data honesty**

- Edges come only from API identifiers: `CustomDomainResponse.app_id`, `CronResponse.app_id`, the per-app bucket list, and `ManagedPostgresBinding.app_id` / `database_id`. Never infer an edge from names or proximity.
- Unknown is never drawn as empty. A failed read is not an empty list, and missing metrics are not `0`.
- Particle density comes only from a real `request_count`. Zero or unknown traffic means no particles.

**Theming**

- No literal hex and no `dark:` in components. Every new colour is a token defined in both `:root` and `.console` in `src/index.css`.
- `src/lib/conventions.test.ts` is extended to scan `src/components/canvas`.

**Motion**

- Use only `--motion-ease` and `--motion-fast/base/slow` (CSS), or `EASE` / `DURATION` from `src/components/dashboard/motion.tsx` (JS).
- Under reduced motion, particles become a static stroke and breathing stops.

**Writes**

- Creates reuse `useAddDomain`, `useCreateCron` and a new `useCreateObjectBucket`. The client already adds `Idempotency-Key` to POSTs (`src/lib/api/client.ts:51`).
- The draft node is the confirmation step: no modal.
- Branch on `ApiError.code`, never on status text.

**Gates**

- `npm run check` (typecheck, lint with `--max-warnings 8` unchanged, format check, tests) and `npm run build`.
- Never hand-edit `src/routeTree.gen.ts`. It is regenerated by any `vite` run (see Task 1).

**Commits**

- Conventional style (`feat(canvas): …`, `test(canvas): …`).
- Run `npx prettier --write` on touched files before committing.

## Review Focus

These five inputs and failure modes are most likely to bite a real user. Each one has a pinning test added to its owning task.

1. **An app with two or more custom domains.** Expect no double-counted traffic: particles appear only when the app has exactly one ingress path. Pinned in Task 3: `does not split or duplicate traffic across several domains`.
2. **A domain or cron whose `app_id` points at a deleted app.** Expect it to be dropped from the graph and reported in `issues`, with no crash and no dangling edge. Pinned in Task 3: `drops and reports orphans`.
3. **An account without the internal Postgres capability.** `GET /v1/postgres/databases` answers 403 or 404. Expect the canvas to render without Postgres nodes and no error state. Pinned in Task 5: `treats a forbidden or missing Postgres surface as absent`.
4. **Free plan.** The metrics endpoints answer 402. Expect nodes to show no numbers (never `0`), and the panel to say "Metrics need Hobby". Pinned in Task 6 (`AppNode never prints a number it was not given`) and Task 8 (`says metrics need Hobby on 402`).
5. **Pressing ↵ twice on a draft, or clicking Create twice.** Expect exactly one API call. Pinned in Task 10: `submits once while the create is pending`.

```tsx
// src/routes/dashboard.canvas.tsx
import { lazy, Suspense } from 'react';
import { createFileRoute, redirect } from '@tanstack/react-router';
import { featureFlags } from '@/lib/feature-flags';
import { consoleHead } from '@/lib/seo';
import { LoadingState } from '@/components/dashboard/primitives';

/**
 * The import sits behind the literal flag on purpose. With the flag unset,
 * Rollup folds the condition to `false`, drops the `import()` and never emits
 * the canvas chunk or its CSS. A static import would keep both in `dist/`.
 */
const CanvasPage = featureFlags.canvas
  ? lazy(() => import('@/components/canvas/canvas-page'))
  : null;

type CanvasSearch = { node?: string };

export const Route = createFileRoute('/dashboard/canvas')({
  head: () => consoleHead('canvas'),
  validateSearch: (search: Record<string, unknown>): CanvasSearch =>
    typeof search.node === 'string' && search.node ? { node: search.node } : {},
  beforeLoad: () => {
    if (!featureFlags.canvas) throw redirect({ to: '/dashboard', replace: true });
  },
  component: CanvasRoute,
});

function CanvasRoute() {
  const { node } = Route.useSearch();
  if (!CanvasPage) return null;
  return (
    <Suspense fallback={<LoadingState message="Loading canvas…" className="m-6" />}>
      <CanvasPage node={node} />
    </Suspense>
  );
}
```

```ts
/** Shared by the Storage page and the canvas, which fans it out per app. */
export function bucketListOptions(slug: string) {
  return queryOptions({
    queryKey: bucketKey(slug),
    queryFn: () => unwrap(api.GET('/v1/apps/{slug}/buckets', { params: { path: { slug } } })),
    enabled: !!slug,
    retry: false,
  });
}

export function useObjectBuckets(slug: string) {
  return useQuery(bucketListOptions(slug));
}

/** Creates stay pessimistic: the server mints the id, scope default and state. */
export function useCreateObjectBucket(slug: string) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: ({ name, region }: { name: string; region?: string }) =>
      unwrap(
        api.POST('/v1/apps/{slug}/buckets', {
          params: { path: { slug } },
          body: { name, scope: 'default', ...(region ? { region } : {}) },
        })
      ),
    onSuccess: () => qc.invalidateQueries({ queryKey: bucketKey(slug) }),
  });
}
```

```ts
    name,

    region: String(body.region ?? 'eu-central'),
    state: 'ready' as const,
    created_at: new Date().toISOString(),
  };
  db.buckets.set(a.slug, [...list, created]);
```

```ts
// src/components/canvas/topology.ts
import type { App, AppsMetrics } from '@/lib/api/queries';
import type { components } from '@/lib/api/schema';
import { toRunState } from '@/lib/api/adapters';

/**
 * The canvas's data model, and the only place an edge is decided.
 *
 * Every edge is read off an identifier the API returned: a domain's `app_id`,
 * a cron's `app_id`, an app's own bucket list, a Postgres binding's
 * `app_id`/`database_id`. Nothing is inferred from names, and anything that
 * points at an app we cannot see is dropped and reported rather than drawn.
 */

type S = components['schemas'];
export type Domain = S['CustomDomainResponse'];
export type Cron = S['CronResponse'];
export type BucketList = S['ObjectBucketList'];
export type PostgresDatabase = S['ManagedPostgresDatabase'];
export type PostgresBinding = S['ManagedPostgresBinding'];

export type Read<T> =
  { status: 'ready'; data: T } | { status: 'loading' } | { status: 'error'; error: unknown };

export type AppPhase = 'running' | 'parked' | 'idle' | 'deploying' | 'error' | 'undeployed';

export interface InternetData {
  kind: 'internet';
}
export interface DomainData {
  kind: 'domain';
  domain: string;
  verified: boolean;
  txtRecord: string | null;
  appSlug: string;
}
export interface AppData {
  kind: 'app';
  slug: string;
  phase: AppPhase;
  requests24h?: number;
  p95Ms?: number;
  metrics: 'ready' | 'loading' | 'unavailable';
  connections: 'ready' | 'loading' | 'error';
  /** Only known once the app's bucket list has answered. */
  buckets?: { enabled: boolean; atLimit: boolean; defaultRegion: string };
}
export interface CronData {
  kind: 'cron';
  id: string;
  schedule: string;
  path: string;
  timezone: string;
  enabled: boolean;
  lastFiredAt: string | null;
  appSlug: string;
}
export interface BucketData {
  kind: 'bucket';
  appSlug: string;
  name: string;
  state: string;
}
export interface PostgresData {
  kind: 'postgres';
  id: string;
  name: string;
  state: string;
}
export type CanvasNodeData =
  InternetData | DomainData | AppData | CronData | BucketData | PostgresData;
export type CanvasNodeKind = CanvasNodeData['kind'];

export interface CanvasNode {
  id: string;
  data: CanvasNodeData;
}
export type EdgeKind = 'ingress' | 'schedule' | 'storage' | 'database';
export interface CanvasEdge {
  id: string;
  source: string;
  target: string;
  kind: EdgeKind;
  /** Present only when the edge carries a known, unshared request count. */
  requests24h?: number;
  pending?: boolean;
}
export interface TopologyIssue {
  kind: 'orphan' | 'read_failed';
  ref: string;
  detail: string;
}
export interface Topology {
  nodes: CanvasNode[];
  edges: CanvasEdge[];
  issues: TopologyIssue[];
}

export interface TopologyInput {
  apps: App[];
  domains: Domain[];
  crons: Cron[];
  metrics: Read<AppsMetrics>;
  /** Keyed by app slug. A missing key reads as still loading. */
  buckets: Record<string, Read<BucketList>>;
  postgres: Read<{ databases: PostgresDatabase[]; bindings: PostgresBinding[] }>;
}

export const nodeId = {
  internet: 'internet',
  domain: (domain: string) => `domain:${domain}`,
  app: (slug: string) => `app:${slug}`,
  cron: (id: string) => `cron:${id}`,
  bucket: (slug: string, name: string) => `bucket:${slug}/${name}`,
  postgres: (id: string) => `postgres:${id}`,
};

/** `evicted_cold`/`parked` is scale-to-zero at rest, the state the canvas breathes. */
export function appPhase(status: string | undefined): AppPhase {
  const s = (status ?? '').toLowerCase();
  if (s === 'evicted_cold' || s === 'parked') return 'parked';
  if (s === 'undeployed') return 'undeployed';
  return toRunState(s);
}

const GONE = new Set(['deleting', 'deleted']);

export function buildTopology(input: TopologyInput): Topology {
  const nodes: CanvasNode[] = [];
  const edges: CanvasEdge[] = [];
  const issues: TopologyIssue[] = [];
  const apps = [...input.apps].sort((a, b) => a.slug.localeCompare(b.slug));
  if (apps.length === 0) return { nodes, edges, issues };

  const slugById = new Map(apps.map((a) => [a.id, a.slug]));
  const rows = input.metrics.status === 'ready' ? input.metrics.data.apps : null;
  const metricsLoading = input.metrics.status === 'loading';

  const domainsBySlug = new Map<string, Domain[]>();
  for (const d of [...input.domains].sort((a, b) => a.domain.localeCompare(b.domain))) {
    const slug = slugById.get(d.app_id);
    if (!slug) {
      issues.push({
        kind: 'orphan',
        ref: nodeId.domain(d.domain),
        detail: `points at unknown app ${d.app_id}`,
      });
      continue;
    }
    domainsBySlug.set(slug, [...(domainsBySlug.get(slug) ?? []), d]);
  }

  nodes.push({ id: nodeId.internet, data: { kind: 'internet' } });

  for (const a of apps) {
    const row = rows?.[a.slug];
    const read = input.buckets[a.slug] ?? { status: 'loading' };
    const appNode = nodeId.app(a.slug);
    nodes.push({
      id: appNode,
      data: {
        kind: 'app',
        slug: a.slug,
        phase: appPhase(a.status),
        requests24h: row?.request_count,
        p95Ms: row?.latency_p95_ms,
        metrics: metricsLoading ? 'loading' : row ? 'ready' : 'unavailable',
        connections: read.status,
        buckets:
          read.status === 'ready'
            ? {
                enabled: read.data.enabled,
                atLimit: read.data.items.length >= read.data.max_buckets_per_app,
                defaultRegion: read.data.default_region,
              }
            : undefined,
      },
    });

    const domains = domainsBySlug.get(a.slug) ?? [];
    // One ingress path carries the app's whole count. With several, the API
    // has no per-host split, so no edge claims a share.
    const ingress = domains.length <= 1 ? row?.request_count : undefined;
    if (domains.length === 0 && a.url) {
      edges.push({
        id: `ingress:internet>${a.slug}`,
        source: nodeId.internet,
        target: appNode,
        kind: 'ingress',
        requests24h: ingress,
      });
    }
    for (const d of domains) {
      const dn = nodeId.domain(d.domain);
      nodes.push({
        id: dn,
        data: {
          kind: 'domain',
          domain: d.domain,
          verified: d.verified,
          txtRecord: d.txt_record ?? null,
          appSlug: a.slug,
        },
      });
      edges.push({
        id: `ingress:internet>${d.domain}`,
        source: nodeId.internet,
        target: dn,
        kind: 'ingress',
        requests24h: ingress,
        pending: !d.verified,
      });
      edges.push({
        id: `ingress:${d.domain}>${a.slug}`,
        source: dn,
        target: appNode,
        kind: 'ingress',
        requests24h: ingress,
        pending: !d.verified,
      });
    }

    if (read.status === 'error') {
      issues.push({ kind: 'read_failed', ref: appNode, detail: 'bucket list' });
    } else if (read.status === 'ready') {
      for (const b of [...read.data.items].sort((x, y) => x.name.localeCompare(y.name))) {
        if (GONE.has(b.state)) continue;
        const bn = nodeId.bucket(a.slug, b.name);
        nodes.push({
          id: bn,
          data: { kind: 'bucket', appSlug: a.slug, name: b.name, state: b.state },
        });
        edges.push({
          id: `storage:${a.slug}>${b.name}`,
          source: appNode,
          target: bn,
          kind: 'storage',
        });
      }
    }
  }

  for (const c of [...input.crons].sort((a, b) => a.id.localeCompare(b.id))) {
    const slug = slugById.get(c.app_id);
    if (!slug) {
      issues.push({
        kind: 'orphan',
        ref: nodeId.cron(c.id),
        detail: `points at unknown app ${c.app_id}`,
      });
      continue;
    }
    nodes.push({
      id: nodeId.cron(c.id),
      data: {
        kind: 'cron',
        id: c.id,
        schedule: c.schedule,
        path: c.path,
        timezone: c.timezone,
        enabled: c.enabled,
        lastFiredAt: c.last_fired_at ?? null,
        appSlug: slug,
      },
    });
    edges.push({
      id: `schedule:${c.id}`,
      source: nodeId.cron(c.id),
      target: nodeId.app(slug),
      kind: 'schedule',
    });
  }

  if (input.postgres.status === 'ready') {
    const { databases, bindings } = input.postgres.data;
    for (const db of [...databases].sort((a, b) => a.name.localeCompare(b.name))) {
      if (GONE.has(db.state)) continue;
      nodes.push({
        id: nodeId.postgres(db.id),
        data: { kind: 'postgres', id: db.id, name: db.name, state: db.state },
      });
    }
    const live = new Set(nodes.map((n) => n.id));
    for (const b of bindings) {
      if (GONE.has(b.state)) continue;
      const slug = slugById.get(b.app_id);
      const target = nodeId.postgres(b.database_id);
      if (!slug || !live.has(target)) {
        issues.push({
          kind: 'orphan',
          ref: `binding:${b.id}`,
          detail: 'binding to an unknown app or database',
        });
        continue;
      }
      edges.push({
        id: `database:${slug}>${b.database_id}`,
        source: nodeId.app(slug),
        target,
        kind: 'database',
      });
    }
  } else if (input.postgres.status === 'error') {
    issues.push({ kind: 'read_failed', ref: 'postgres', detail: 'postgres databases' });
  }

  return { nodes, edges, issues };
}
```

```ts
// src/components/canvas/traffic.ts
/**
 * Request count → edge motion. A log scale on requests per hour, because a
 * linear one makes every small app look dead next to one busy one. Zero or
 * unknown traffic gets nothing: motion on the canvas is evidence, never
 * decoration.
 */
export function particles(requests24h: number | undefined) {
  const perHour =
    requests24h && Number.isFinite(requests24h) && requests24h > 0 ? requests24h / 24 : 0;
  if (perHour === 0) return { count: 0, durationS: 0, strokeWidth: 1 };
  const count = Math.min(4, Math.max(1, Math.ceil(Math.log10(perHour + 1))));
  return { count, durationS: 2.8 - count * 0.35, strokeWidth: 1 + count * 0.5 };
}
```

```ts
// src/components/canvas/layout.ts
import type { CanvasNodeKind, Topology } from './topology';
import { nodeId } from './topology';

/**
 * Deterministic columns, no layout engine: Internet, then domains, then apps,
 * then what the apps talk to. Each app owns a horizontal band, so a glance
 * down the app column is a glance down the account. Positions are top-left,
 * as React Flow expects.
 */
export const NODE_SIZE: Record<CanvasNodeKind, { w: number; h: number }> = {
  internet: { w: 40, h: 40 },
  domain: { w: 210, h: 48 },
  app: { w: 230, h: 68 },
  cron: { w: 210, h: 48 },
  bucket: { w: 190, h: 48 },
  postgres: { w: 190, h: 48 },
};

export type Point = { x: number; y: number };

const COLUMN = { internet: 0, domain: 120, app: 440, resource: 790 };
const ROW = 88; // tallest node (68) + 20
const STACK = 64; // 48 + 16, for crons above an app
const BAND_GAP = 56;

export function layout(t: Topology): Map<string, Point> {
  const pos = new Map<string, Point>();
  const kindOf = new Map(t.nodes.map((n) => [n.id, n.data.kind]));
  const apps = t.nodes.filter((n) => n.data.kind === 'app');
  let cursor = 0;

  for (const app of apps) {
    const crons = t.edges
      .filter((e) => e.kind === 'schedule' && e.target === app.id)
      .map((e) => e.source);
    const domains = t.edges
      .filter(
        (e) => e.kind === 'ingress' && e.target === app.id && kindOf.get(e.source) === 'domain'
      )
      .map((e) => e.source);
    // A shared database is placed with the first app that binds it.
    const resources = t.edges
      .filter(
        (e) =>
          (e.kind === 'storage' || e.kind === 'database') &&
          e.source === app.id &&
          !pos.has(e.target)
      )
      .map((e) => e.target)
      .filter((id, i, all) => all.indexOf(id) === i);

    crons.forEach((id, i) => pos.set(id, { x: COLUMN.app + 10, y: cursor + i * STACK }));
    const top = cursor + crons.length * STACK;
    const rows = Math.max(1, domains.length, resources.length);
    const height = rows * ROW - 20;
    pos.set(app.id, { x: COLUMN.app, y: top + (height - NODE_SIZE.app.h) / 2 });
    domains.forEach((id, i) => pos.set(id, { x: COLUMN.domain, y: top + i * ROW + 10 }));
    resources.forEach((id, i) => pos.set(id, { x: COLUMN.resource, y: top + i * ROW + 10 }));
    cursor = top + height + BAND_GAP;
  }

  // Databases nothing binds still exist; they sit in a final band.
  const loose = t.nodes.filter((n) => n.data.kind === 'postgres' && !pos.has(n.id));
  loose.forEach((n, i) => pos.set(n.id, { x: COLUMN.resource, y: cursor + i * ROW }));
  if (loose.length) cursor += loose.length * ROW + BAND_GAP;

  if (t.nodes.some((n) => n.id === nodeId.internet)) {
    pos.set(nodeId.internet, {
      x: COLUMN.internet,
      y: Math.max(0, (cursor - BAND_GAP) / 2 - NODE_SIZE.internet.h / 2),
    });
  }
  return pos;
}

/** Where a draft opens: below the app, on the side its "+" was pressed. */
export function draftPosition(app: Point, side: 'in' | 'out'): Point {
  return side === 'in'
    ? { x: app.x - 290, y: app.y + NODE_SIZE.app.h + 24 }
    : { x: app.x + NODE_SIZE.app.w + 60, y: app.y + NODE_SIZE.app.h + 24 };
}
```

```ts
// src/components/canvas/use-topology.ts
import { useMemo } from 'react';
import { useQueries } from '@tanstack/react-query';
import {
  postgresBindingsOptions,
  useApps,
  useAppsMetrics,
  useCrons,
  useDomains,
  usePostgresDatabases,
} from '@/lib/api/queries';
import { bucketListOptions } from '@/lib/api/object-storage';
import { ApiError } from '@/lib/api/errors';
import { queryPhase, type QueryPhase } from '@/components/dashboard/primitives';
import {
  buildTopology,
  type PostgresBinding,
  type PostgresDatabase,
  type Read,
  type Topology,
} from './topology';

type QueryLike<T> = { data?: T; error: unknown; isPending: boolean; fetchStatus: string };

/** A disabled query reports `isPending` forever; only a fetching one is loading. */
export function toRead<T>(q: QueryLike<T>): Read<T> {
  if (q.data !== undefined) return { status: 'ready', data: q.data };
  if (q.error) return { status: 'error', error: q.error };
  return { status: 'loading' };
}

/**
 * Managed Postgres is an internal capability. An account without it answers
 * 403 or 404, which is "there is no Postgres here", not a failure to draw.
 */
export function postgresRead(
  databases: QueryLike<{ items: PostgresDatabase[] }>,
  bindings: QueryLike<{ items: PostgresBinding[] }>[]
): Read<{ databases: PostgresDatabase[]; bindings: PostgresBinding[] }> {
  if (
    databases.error instanceof ApiError &&
    (databases.error.isForbidden || databases.error.isNotFound)
  ) {
    return { status: 'ready', data: { databases: [], bindings: [] } };
  }
  const dbs = toRead(databases);
  if (dbs.status !== 'ready') return dbs;
  const reads = bindings.map(toRead);
  const failed = reads.find((r) => r.status === 'error');
  if (failed) return failed;
  if (reads.some((r) => r.status === 'loading')) return { status: 'loading' };
  return {
    status: 'ready',
    data: {
      databases: dbs.data.items,
      bindings: reads.flatMap((r) => (r.status === 'ready' ? r.data.items : [])),
    },
  };
}

export function useTopology(): {
  phase: QueryPhase;
  error: unknown;
  topology: Topology;
  retry: () => void;
} {
  const apps = useApps();
  const domains = useDomains();
  const crons = useCrons();
  const metrics = useAppsMetrics('24h', { retry: false });
  const databases = usePostgresDatabases();

  const slugs = useMemo(() => (apps.data ?? []).map((a) => a.slug), [apps.data]);
  // Per-app reads wait for the app list, so none of them is a disabled
  // query masquerading as loading.
  const buckets = useQueries({ queries: slugs.map((slug) => bucketListOptions(slug)) });
  const bindings = useQueries({
    queries: (databases.data?.items ?? []).map((db) => postgresBindingsOptions(db.id)),
  });

  const error = apps.error ?? domains.error ?? crons.error;
  const phase = queryPhase({
    error,
    loading: apps.isPending || domains.isPending || crons.isPending,
    isEmpty: apps.data?.length === 0,
  });

  const topology = useMemo(
    () =>
      buildTopology({
        apps: apps.data ?? [],
        domains: domains.data ?? [],
        crons: crons.data ?? [],
        metrics: toRead(metrics),
        buckets: Object.fromEntries(slugs.map((slug, i) => [slug, toRead(buckets[i])])),
        postgres: postgresRead(databases, bindings),
      }),
    [apps.data, domains.data, crons.data, metrics, slugs, buckets, databases, bindings]
  );

  const retry = () => {
    void apps.refetch();
    void domains.refetch();
    void crons.refetch();
  };

  return { phase, error, topology, retry };
}
```

```tsx
// src/components/canvas/wind-edge.tsx
import { BaseEdge, getBezierPath, type Edge, type EdgeProps } from '@xyflow/react';
import { useReducedMotion } from 'motion/react';
import { particles } from './traffic';

export type WindEdgeData = { requests24h?: number; pending?: boolean; draft?: boolean };
export type WindFlowEdge = Edge<WindEdgeData, 'wind'>;

/**
 * Requests travel as mint particles, as many as the real count earns.
 * Reduced motion swaps them for a static mint stroke whose width carries the
 * same reading.
 */
export function WindEdge({
  id,
  sourceX,
  sourceY,
  targetX,
  targetY,
  sourcePosition,
  targetPosition,
  data,
}: EdgeProps<WindFlowEdge>) {
  const reduce = useReducedMotion();
  const [path] = getBezierPath({
    sourceX,
    sourceY,
    targetX,
    targetY,
    sourcePosition,
    targetPosition,
  });
  const traffic = particles(data?.requests24h);

  if (data?.draft) {
    return (
      <BaseEdge
        id={id}
        path={path}
        style={{
          stroke: 'var(--brand)',
          strokeOpacity: 0.55,
          strokeDasharray: '3 4',
          animation: reduce ? undefined : 'canvas-march 1s linear infinite',
        }}
      />
    );
  }
  if (data?.pending) {
    return (
      <BaseEdge
        id={id}
        path={path}
        style={{ stroke: 'var(--status-warning)', strokeOpacity: 0.5, strokeDasharray: '2 4' }}
      />
    );
  }
  return (
    <>
      <BaseEdge
        id={id}
        path={path}
        style={
          reduce && traffic.count > 0
            ? { stroke: 'var(--brand)', strokeOpacity: 0.7, strokeWidth: traffic.strokeWidth }
            : { stroke: 'var(--canvas-edge)', strokeWidth: 1 }
        }
      />
      {!reduce &&
        Array.from({ length: traffic.count }, (_, i) => (
          <circle
            key={i}
            r={traffic.count > 2 ? 1.8 : 1.4}
            style={{ fill: 'var(--brand)' }}
            opacity={0.9}
          >
            <animateMotion
              dur={`${traffic.durationS}s`}
              begin={`${((i * traffic.durationS) / traffic.count).toFixed(2)}s`}
              repeatCount="indefinite"
              path={path}
            />
          </circle>
        ))}
    </>
  );
}

export const edgeTypes = { wind: WindEdge };
```

```ts
// src/components/canvas/flow.ts
import type { FlowNode, ConnectSide } from './nodes';
import type { WindFlowEdge } from './wind-edge';
import type { Point } from './layout';
import type { Topology } from './topology';

export function toFlow(
  t: Topology,
  pos: Map<string, Point>,
  onConnect?: (slug: string, side: ConnectSide) => void
): { nodes: FlowNode[]; edges: WindFlowEdge[] } {
  const nodes: FlowNode[] = t.nodes.map((n) => ({
    id: n.id,
    type: n.data.kind,
    position: pos.get(n.id) ?? { x: 0, y: 0 },
    data:
      n.data.kind === 'app' && onConnect
        ? {
            ...n.data,
            onConnect: (side: ConnectSide) => onConnect((n.data as { slug: string }).slug, side),
          }
        : n.data,
    connectable: false,
  }));
  const edges: WindFlowEdge[] = t.edges.map((e) => ({
    id: e.id,
    source: e.source,
    target: e.target,
    type: 'wind',
    sourceHandle: 'out',
    targetHandle: e.kind === 'schedule' ? 'top' : 'in',
    data: { requests24h: e.requests24h, pending: e.pending },
    selectable: false,
  }));
  return { nodes, edges };
}
```

```tsx
              <p className="mt-1 text-sm font-semibold">Nothing to draw yet</p>
              <p className="mt-1 text-xs text-muted-foreground">
                Domains, crons and buckets all hang off an app. Deploy one and it appears here.
              </p>
              <Button asChild className="mt-4 w-full">
                <Link to="/dashboard/workflows/new">Deploy an app</Link>
              </Button>
            </div>
          </div>
        )}
        {phase === 'ready' && (
          <>
            <div className="relative flex-1">
              <CanvasView nodes={flow.nodes} edges={flow.edges} selected={node} onSelect={select} />
            </div>
            {selected && (
              <Inspector node={selected} topology={topology} onClose={() => select(undefined)} />
            )}
          </>
        )}
      </div>
    </div>
  );
```

```ts
// src/components/canvas/create.ts
import { ApiError } from '@/lib/api/errors';
import { isCronSchedule } from '@/lib/cron-schedule';
import type { ConnectSide } from './nodes';

export type CreateKind = 'domain' | 'cron' | 'bucket';

/** Ports are directional: left adds traffic into an app, right adds what it talks to. */
export const CREATE_OPTIONS: Record<
  ConnectSide,
  { kind: CreateKind; label: string; hint: string; key: string }[]
> = {
  in: [
    { kind: 'domain', label: 'Domain', hint: 'Route a hostname to this app', key: 'd' },
    { kind: 'cron', label: 'Cron', hint: 'Call it on a schedule', key: 'c' },
  ],
  out: [{ kind: 'bucket', label: 'Bucket', hint: 'Store objects for this app', key: 'b' }],
};

/** Shape only. The server is the authority on what it will accept. */
export function validateHostname(v: string): string | undefined {
  const host = v.trim();
  if (!host) return 'Enter a hostname.';
  if (!/^(?=.{1,253}$)([a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?\.)+[a-z]{2,63}$/.test(host))
    return 'Use a bare hostname like api.example.com, with no scheme or path.';
}

export function validateBucketName(v: string): string | undefined {
  if (!/^[a-z][a-z0-9-]{0,62}$/.test(v))
    return 'Start with a lowercase letter; then lowercase letters, digits and dashes (max 63).';
}

export function validateCron({
  schedule,
  path,
}: {
  schedule: string;
  path: string;
}): string | undefined {
  if (!isCronSchedule(schedule))
    return 'A schedule has five fields: minute hour day month weekday.';
  if (path && !path.startsWith('/')) return 'The path must start with /.';
}

const KNOWN: Record<string, string> = {
  invalid_domain: 'That hostname is not valid.',
  domain_exists: 'That hostname is already connected to an app.',
  invalid_schedule: 'A schedule has five fields: minute hour day month weekday.',
  cron_invalid: 'The schedule was rejected. Check each field.',
  object_storage_invalid: 'Bucket names are lowercase letters, digits and dashes.',
  object_storage_conflict:
    'A bucket with that name already exists, or the app is at its bucket limit.',
  object_storage_unavailable: 'Object storage is not enabled for this account.',
  app_not_found: 'That app no longer exists.',
};

/** Branch on the code; the server's own prose for anything unknown. */
export function createErrorMessage(e: unknown): string {
  if (e instanceof ApiError) return KNOWN[e.code] ?? e.message;
  if (e instanceof Error && e.message) return e.message;
  return 'Something went wrong. Try again.';
}
```

```tsx
// src/components/canvas/connect-menu.tsx
import { useEffect, useRef } from 'react';
import { Globe, HardDrive, Timer } from 'iconoir-react';
import { cn } from '@/lib/utils';
import { CREATE_OPTIONS, type CreateKind } from './create';
import type { ConnectSide } from './nodes';
import type { Point } from './layout';
import type { AppData } from './topology';

const ICON = { domain: Globe, cron: Timer, bucket: HardDrive } as const;
const TINT = {
  domain: 'var(--cat-network)',
  cron: 'var(--cat-compute)',
  bucket: 'var(--cat-storage)',
} as const;

function disabledReason(kind: CreateKind, app: AppData): string | undefined {
  if (kind !== 'bucket') return;
  if (!app.buckets) return 'Checking storage…';
  if (!app.buckets.enabled) return 'Object storage is not enabled for this account.';
  if (app.buckets.atLimit) return 'This app is at its bucket limit.';
}

export function ConnectMenu({
  app,
  side,
  at,
  onPick,
  onClose,
}: {
  app: AppData;
  side: ConnectSide;
  at: Point;
  onPick: (kind: CreateKind) => void;
  onClose: () => void;
}) {
  const ref = useRef<HTMLDivElement>(null);
  const options = CREATE_OPTIONS[side];

  useEffect(() => {
    ref.current?.querySelector<HTMLButtonElement>('[role="menuitem"]:not(:disabled)')?.focus();
    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') return onClose();
      const hit = options.find(
        (o) => o.key === e.key.toLowerCase() && !disabledReason(o.kind, app)
      );
      if (hit) onPick(hit.kind);
    };
    const onDown = (e: PointerEvent) => !ref.current?.contains(e.target as Node) && onClose();
    window.addEventListener('keydown', onKey);
    window.addEventListener('pointerdown', onDown);
    return () => {
      window.removeEventListener('keydown', onKey);
      window.removeEventListener('pointerdown', onDown);
    };
  }, [app, onClose, onPick, options]);

  return (
    <div
      ref={ref}
      role="menu"
      aria-label={side === 'in' ? `Send traffic into ${app.slug}` : `Connect ${app.slug} to`}
      className="nodrag nopan absolute z-10 w-64 animate-item-enter rounded-[10px] border border-border bg-popover p-1.5 shadow-elevation-3"
      style={{ transform: `translate(${at.x}px, ${at.y}px)` }}
    >
      <p className="label-mono px-2 pb-1 pt-1.5 text-[10.5px] text-muted-foreground">
        {side === 'in' ? `Send traffic into ${app.slug}` : `Connect ${app.slug} to`}
      </p>
      {options.map((o) => {
        const Icon = ICON[o.kind];
        const reason = disabledReason(o.kind, app);
        return (
          <button
            key={o.kind}
            type="button"
            role="menuitem"
            disabled={Boolean(reason)}
            onClick={() => onPick(o.kind)}
            className={cn(
              'flex w-full items-center gap-2.5 rounded-md px-2 py-1.5 text-left',
              'hover:bg-accent focus-visible:bg-accent focus-visible:outline-none disabled:opacity-50'
            )}
          >
            <span
              aria-hidden
              className="grid size-[26px] place-items-center rounded-md [&>svg]:size-3.5"
              style={{
                color: TINT[o.kind],
                background: `color-mix(in srgb, ${TINT[o.kind]} 16%, transparent)`,
              }}
            >
              <Icon />
            </span>
            <span className="min-w-0 flex-1">
              <span className="block text-[13px] font-semibold">{o.label}</span>
              <span className="block text-xs text-muted-foreground">{reason ?? o.hint}</span>
            </span>
            <kbd
              aria-hidden
              className="rounded border border-border-secondary px-1 font-mono text-[10px] uppercase text-muted-foreground"
            >
              {o.key}
            </kbd>
          </button>
        );
      })}
    </div>
  );
}
```

```tsx
// src/components/canvas/draft-node.tsx
import { useState, type KeyboardEvent } from 'react';
import { Handle, Position, type Node, type NodeProps } from '@xyflow/react';
import { useAddDomain, useCreateCron } from '@/lib/api/queries';
import { useCreateObjectBucket } from '@/lib/api/object-storage';
import { Button } from '@/components/ui/button';
import {
  createErrorMessage,
  validateBucketName,
  validateCron,
  validateHostname,
  type CreateKind,
} from './create';

/**
 * The draft is the confirmation step: it already says what will be created
 * and where. ↵ commits, esc dissolves. Single-field creates type straight
 * in; a cron grows into a compact form in place.
 */
type DraftProps = {
  kind: CreateKind;
  app: { slug: string; id: string; defaultRegion?: string };
  onDone: () => void;
  onCancel: () => void;
};

export function DraftNode({ kind, app, onDone, onCancel }: DraftProps) {
  const domain = useAddDomain();
  const cron = useCreateCron();
  const bucket = useCreateObjectBucket(app.slug);
  const active = kind === 'domain' ? domain : kind === 'cron' ? cron : bucket;
  const [value, setValue] = useState('');
  const [schedule, setSchedule] = useState('');
  const [path, setPath] = useState('/');
  const [invalid, setInvalid] = useState<string>();
  const error = invalid ?? (active.error ? createErrorMessage(active.error) : undefined);
  const done = { onSuccess: onDone };

  const submit = () => {
    if (active.isPending) return;
    if (kind === 'domain') {
      const host = value.trim().toLowerCase();
      const problem = validateHostname(host);
      setInvalid(problem);
      if (!problem) domain.mutate({ domain: host, app_id: app.id }, done);
    } else if (kind === 'bucket') {
      const problem = validateBucketName(value);
      setInvalid(problem);
      if (!problem) bucket.mutate({ name: value, region: app.defaultRegion }, done);
    } else {
      const problem = validateCron({ schedule, path });
      setInvalid(problem);
      if (!problem)
        cron.mutate({ app_id: app.id, schedule: schedule.trim(), path: path || '/' }, done);
    }
  };

  const keys = (e: KeyboardEvent) => {
    if (e.key === 'Escape') onCancel();
    if (e.key === 'Enter') {
      e.preventDefault();
      submit();
    }
  };

  const field =
    'h-8 w-full rounded-[var(--console-control-radius)] border border-input bg-background px-2.5 text-[13px] outline-none focus:border-brand focus:ring-[3px] focus:ring-brand-muted';

  return (
    <div
      className="nodrag nopan w-[230px] animate-item-enter rounded-[10px] border border-dashed border-brand/60 bg-canvas-glass p-2.5 shadow-elevation-2 backdrop-blur-md"
      onKeyDown={keys}
    >
      <p className="label-mono text-[10.5px] text-brand">New {kind}</p>
      <p className="mb-2 text-[11px] text-muted-foreground">→ creates on {app.slug}</p>
      {kind === 'cron' ? (
        <div className="flex flex-col gap-2">
          <label className="text-[11px] text-muted-foreground">
            Schedule
            <input
              autoFocus
              aria-label="Schedule"
              className={`${field} font-mono`}
              placeholder="0 3 * * *"
              value={schedule}
              onChange={(e) => setSchedule(e.target.value)}
            />
          </label>
          <label className="text-[11px] text-muted-foreground">
            Path
            <input
              aria-label="Path"
              className={`${field} font-mono`}
              value={path}
              onChange={(e) => setPath(e.target.value)}
            />
          </label>
          <p className="text-[11px] text-muted-foreground">Times are UTC.</p>
          <div className="flex justify-end gap-1.5">
            <Button size="xs" variant="ghost" onClick={onCancel}>
              Cancel
            </Button>
            <Button size="xs" onClick={submit} disabled={active.isPending}>
              Create cron
            </Button>
          </div>
        </div>
      ) : (
        <input
          autoFocus
          aria-label={kind === 'domain' ? 'Hostname' : 'Bucket name'}
          className={field}
          placeholder={kind === 'domain' ? 'api.example.com' : 'orders'}
          value={value}
          disabled={active.isPending}
          onChange={(e) => setValue(e.target.value)}
        />
      )}
      {error ? (
        <p role="alert" className="mt-1.5 text-[11px] text-status-critical">
          {error}
        </p>
      ) : (
        kind !== 'cron' && (
          <p className="mt-1.5 text-[11px] text-muted-foreground">↵ create · esc cancel</p>
        )
      )}
    </div>
  );
}
```
