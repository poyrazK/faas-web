# Canvas v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the canvas top-notch in two parts. Part A brings every existing surface onto one design system and fixes the open UX gaps (focus mode, toolbar, jump-to-node, minimap, inspector, room-making drafts, keyboard menu). Part B adds a wizard-first entry for empty accounts that deploys an app from Git or the CLI and morphs into a live, building app node.

**Architecture:**

- **Part A** reshapes the existing `src/components/canvas` units in place:
  - node anatomy;
  - a pure `layout()` that can reserve room for a draft;
  - pure `neighbourhood()` and `edgeLabel()` helpers;
  - a `useCamera()` hook;
  - a toolbar inside React Flow's `Panel`.
- **Part B** adds:
  - a screen-anchored `Wizard` card in `src/components/canvas/wizard/`, with its step in the route search;
  - a `useCreateAndDeploy()` hook shared with the existing New App wizard;
  - a non-visual `LaunchTracker` that turns a deployment into node state;
  - ghost nodes for next steps.

**Tech Stack:** React 19, TanStack Router/Query 5, `@xyflow/react` 12 (`Panel`, `MiniMap`, `useReactFlow`, `useStore`, `EdgeLabelRenderer`), `motion`, Tailwind 4 tokens, Vitest + RTL, the Vite mock.

**Spec:** `docs/superpowers/specs/2026-10-10-canvas-v2-wizard-and-polish-design.md` (v1 spec: `docs/superpowers/specs/2026-10-10-infrastructure-canvas-design.md`)

## Global Constraints

**Gating**

- Owner-local only. `VITE_FEATURE_CANVAS=1` lives in `.env.development.local`.
- Never push, and never set the flag on Vercel.

**Type scale**

- 14px / 600: node titles.
- 12.5px: body, menu rows and inspector rows.
- 11.5px: metrics rows, with `tabular-nums`.
- 10.5px mono, uppercase, `tracking-[0.06em]`: status and labels.
- 18px / 600: wizard titles and KPI values.
- 20px: front-door title only.

**Spacing and shape**

- 4px grid. Card padding 24px. Node padding 14px horizontal.
- Radii: node 12px, wizard card 16px, menu 12px, tiles and inputs 8–12px.

**Node sizes, fixed per kind**

- App 248×76; domain, cron, bucket and Postgres 216×56; Internet 44×44.
- Exception: an app in a first-deploy state (`waiting` to `failed`) is 96px tall, and `layout()` reserves 96 for it.

**Colour, elevation and focus**

- One mint accent per surface. Category tokens only on glyph tiles and legend dots. Status tokens only on status dots and their words.
- No literal hex and no `dark:` in components (`conventions.test.ts` covers `src/components/canvas`).
- Elevation: nodes at 2; hover, selected, menus and the wizard card at 3.
- Focus: a 2px mint ring with a 2px background gap on everything focusable. Programmatic focus always passes `{ preventScroll: true }`.

**Motion**

- `--motion-ease`, 150 / 240 / 380ms. The card-to-node morph is 600ms.
- Reduced motion: every movement becomes a 150ms cross-fade, particles and breathing stop, and status stays in text.

**Data honesty (from v1)**

- Edges come only from IDs. Unknown is never drawn as empty or as `0`.
- Every unknown value says _why_ ("Metrics on Hobby", "Metrics unavailable").

**API**

- No new API operations, only those already in `api/openapi.yaml`.
- `apid` accepts any `/dashboard/...` path, including a query, as the GitHub return (`dashboardGitHubReturnTo`, faas `cmd/apid/handlers_dashboard_apps_new_post.go`). So the return to `/dashboard/canvas?wizard=source` needs no fallback.

**CLI copy, exactly:**

```
curl -fsSL https://get.gregale.dev | sh
gregale login
gregale deploy --name <name>
```

`--name` is verified in faas `cmd/gregale/commands2.go`.

**Gates**

- `npm run check` (lint ceiling `--max-warnings 8`), `npm run build`, and the flag fold-out both ways (sentinel `data-gregale-canvas`).
- Before `npm run check`, run `npx prettier --write .superpowers` (the git-ignored workspace is format-checked).
- Remove `dist/` before running the suite (`prerender.test.ts` reads it).

## Review Focus

1. **Esc while a wizard step has unsaved input.** Expect it to step back without creating anything. Typed values survive going back and forward within the same open wizard. Pinned in Task 10: `esc steps back and keeps what was typed`.
2. **A deploy that fails _before_ a deployment exists** (bind or source-ref POST rejected after the app was created). Expect the node to show `failed` with "Build was not submitted" and Retry, never a stuck `queued`. Pinned in Task 12: `a rejected submission is a failed launch, not a queued one`.
3. **Reloading during a first deploy.** Expect the node to keep its deploy rail. The launch is recovered from the app's latest deployment, not lost. Pinned in Task 12: `recovers a launch from the latest deployment after reload`.
4. **Typing `/` or `n` inside any input** (wizard field, draft, jump finder). Expect the character to be typed; it must not open the finder or the wizard. Pinned in Task 4: `does not hijack / or n while typing`.
5. **A draft on the last app of a tall graph.** Expect the camera to pan so the whole draft is visible, and nothing underneath to be covered. Pinned in Task 6 (layout no-overlap with a draft in the last band), plus the Task 15 browser check `draft fully on screen`.

Replace `flow.ts`:

```ts
import type { FlowNode, ConnectSide } from './nodes';
import type { WindFlowEdge } from './wind-edge';
import type { Point } from './layout';
import type { Topology } from './topology';

export type FlowOptions = {
  onConnect?: (slug: string, side: ConnectSide) => void;
  onRetry?: (slug: string) => void;
};

export function toFlow(
  t: Topology,
  pos: Map<string, Point>,
  opts: FlowOptions = {}
): { nodes: FlowNode[]; edges: WindFlowEdge[] } {
  const nodes: FlowNode[] = t.nodes.map((n) => {
    const data = n.data;
    return {
      id: n.id,
      type: data.kind,
      position: pos.get(n.id) ?? { x: 0, y: 0 },
      data:
        data.kind === 'app'
          ? {
              ...data,
              ...(opts.onConnect && {
                onConnect: (side: ConnectSide) => opts.onConnect!(data.slug, side),
              }),
              ...(opts.onRetry && { onRetry: () => opts.onRetry!(data.slug) }),
            }
          : data,
      connectable: false,
    };
  });
  const edges: WindFlowEdge[] = t.edges.map((e) => ({
    id: e.id,
    source: e.source,
    target: e.target,
    type: 'wind',
    sourceHandle: 'out',
    targetHandle: e.kind === 'schedule' ? 'top' : 'in',
    data: { requests24h: e.requests24h, pending: e.pending },
    selectable: false,
  }));
  return { nodes, edges };
}
```

// src/components/canvas/focus.ts
import type { Topology } from './topology';

/** The selected node, everything one edge away, and those edges. */
export function neighbourhood(t: Topology, id: string): { nodes: Set<string>; edges: Set<string> } {
  const nodes = new Set([id]);
  const edges = new Set<string>();
  for (const e of t.edges) {
    if (e.source === id || e.target === id) {
      edges.add(e.id);
      nodes.add(e.source);
      nodes.add(e.target);
    }
  }
  return { nodes, edges };
}

```ts
// src/components/canvas/camera.ts
import { useCallback } from 'react';
import { useReactFlow, useStore } from '@xyflow/react';

/** Camera moves the canvas makes on the user's behalf, always on the console curve. */
export function useCamera() {
  const flow = useReactFlow();
  const size = useStore((s) => ({ w: s.width, h: s.height }));

  const flyTo = useCallback(
    (id: string) => {
      const n = flow.getNode(id);
      if (!n) return;
      const w = n.measured?.width ?? 0;
      const h = n.measured?.height ?? 0;
      flow.setCenter(n.position.x + w / 2, n.position.y + h / 2, {
        zoom: Math.max(flow.getZoom(), 1),
        duration: 380,
      });
    },
    [flow]
  );

  /** Pans (never zooms in) so every listed node is fully on screen. */
  const ensureVisible = useCallback(
    (ids: string[]) => {
      const nodes = ids
        .map((id) => flow.getNode(id))
        .filter((n): n is NonNullable<typeof n> => Boolean(n));
      if (!nodes.length) return;
      const box = flow.getNodesBounds(nodes);
      const { x, y, zoom } = flow.getViewport();
      const view = { x: -x / zoom, y: -y / zoom, w: size.w / zoom, h: size.h / zoom };
      const inside =
        box.x >= view.x &&
        box.y >= view.y &&
        box.x + box.width <= view.x + view.w &&
        box.y + box.height <= view.y + view.h;
      if (!inside) void flow.fitBounds(box, { padding: 0.25, duration: 380 });
    },
    [flow, size.w, size.h]
  );

  return { flyTo, ensureVisible };
}

export function ConnectMenu({ app, side, at, onPick, onClose, onRetry }: { app: AppData; side: ConnectSide; at: Point; onPick: (kind: CreateKind) => void; onClose: () => void; onRetry?: () => void }) {
  const ref = useRef<HTMLDivElement>(null);
  const options = CREATE_OPTIONS[side];
  const latest = useRef({ app, onPick, onClose, options });
  latest.current = { app, onPick, onClose, options };

  useEffect(() => {
    ref.current?.querySelector<HTMLButtonElement>('[role="menuitem"]:not(:disabled)')?.focus({ preventScroll: true });
  }, []);

  useEffect(() => {
    const items = () => [...(ref.current?.querySelectorAll<HTMLButtonElement>('[role="menuitem"]:not(:disabled)') ?? [])];
    const onKey = (e: KeyboardEvent) => {
      const { app, onPick, onClose, options } = latest.current;
      if (e.key === 'Escape') return onClose();
      if (e.key === 'ArrowDown' || e.key === 'ArrowUp') {
        e.preventDefault();
        const list = items();
        const i = list.indexOf(document.activeElement as HTMLButtonElement);
        const next = list[(i + (e.key === 'ArrowDown' ? 1 : -1) + list.length) % list.length];
        next?.focus({ preventScroll: true });
        return;
      }
      const hit = options.find((o) => o.key === e.key.toLowerCase() && !disabledReason(o.kind, app));
      if (hit) onPick(hit.kind);
    };
    const onDown = (e: PointerEvent) => !ref.current?.contains(e.target as Node) && latest.current.onClose();
    window.addEventListener('keydown', onKey);
    window.addEventListener('pointerdown', onDown);
    return () => {
      window.removeEventListener('keydown', onKey);
      window.removeEventListener('pointerdown', onDown);
    };
  }, []);
  // render as before, plus the footer below

// --- Canvas wizard support -----------------------------------------------------
/** `MOCK_CANVAS_EMPTY=1`: seed apps stay hidden until the session creates one. */
const CANVAS_EMPTY = process.env.MOCK_CANVAS_EMPTY === '1';
const sessionApps = new Set<string>();
const visibleApp = (id: string) => !CANVAS_EMPTY || sessionApps.has(id);

type Progressing = {
  status: string;
  created_at: string;
  repo?: string;
  error_why?: string;
  error_code?: string;
  error?: string;
};

/** Elapsed-time progression for source-ref deployments, so the canvas can watch a real-shaped build. */
export function advanceDeployment<T extends Progressing>(dep: T, now = Date.now()): T {
  const ms = now - Date.parse(dep.created_at);
  const broken = (dep.repo ?? '').includes('broken');
  if (broken && ms >= 7_000) {
    return {
      ...dep,
      status: 'failed',
      error: 'build failed',
      error_why: "Cannot find module './db'",
      error_code: 'build_failed',
    };
  }
  const status =
    ms < 2_000 ? 'queued' : ms < 7_000 ? 'building' : ms < 10_000 ? 'deploying' : 'active';
  return { ...dep, status };
}
const progressing = new Map<string, string>(); // deployment id → repo
function tick(d: db.Deployment) {
  const repo = progressing.get(d.id);
  if (repo === undefined) return d;
  const next = advanceDeployment({
    ...(d as unknown as Progressing),
    repo,
  }) as unknown as db.Deployment;
  Object.assign(d, next);
  const a = db.apps.find((x) => x.id === d.app_id);
  if (a)
    a.status =
      next.status === 'active' ? 'active' : next.status === 'failed' ? 'error' : 'deploying';
  if (next.status === 'active' || next.status === 'failed') progressing.delete(d.id);
  return d;
}

// src/lib/api/create-and-deploy.ts
import { useCallback } from 'react';
import { useAuth } from '@/lib/auth';
import { useData } from '@/lib/store';
import { useBindRepoFor, useDeployFromRefFor } from './queries';

/**
 * Creating an app and deploying it from Git, in one place, so the New App
 * page and the canvas wizard cannot drift apart. Errors propagate unchanged:
 * the caller decides what a person sees.
 */
export function useCreateAndDeploy() {
  const { account } = useAuth();
  const { addWorkflow } = useData();
  const bindRepo = useBindRepoFor();
  const deployFromRef = useDeployFromRefFor();

  const createApp = useCallback(
    ({ name }: { name: string }) =>
      addWorkflow({ name, runtime: 'node22', memoryMb: 128, type: 'app' }),
    [addWorkflow]
  );

  const deployGit = useCallback(
    async ({ slug, repo, ref }: { slug: string; repo: string; ref: string }) => {
      const installationId = Number(account?.github_install_id);
      if (!Number.isSafeInteger(installationId) || installationId <= 0) {
        throw new Error('Connect GitHub before deploying from a repository.');
      }
      await bindRepo.mutateAsync({ slug, installationId, repo, branch: ref });
      return deployFromRef.mutateAsync({ slug, repo, ref, format: 'tarball' });
    },
    [account?.github_install_id, bindRepo, deployFromRef]
  );

  return { createApp, deployGit };
}

import { appQuotaExceeded, memoryAllowed } from '@/lib/plan';
import { RepoPicker } from '@/components/dashboard/repo-picker';
import { appNameError } from '@/components/dashboard/new-app-validation';
import { isValidGitRef } from '@/components/dashboard/new-app-source';

const PLAN: Record<string, string> = { free: 'Free', hobby: 'Hobby', pro: 'Pro', scale: 'Scale' };

export function StepGit({ onLaunched }: { onLaunched: (l: LaunchSeed) => void }) {
  const { account } = useAuth();
  const { createApp, deployGit } = useCreateAndDeploy();
  const [repo, setRepo] = useState('');
  const [ref, setRef] = useState('main');
  const [name, setName] = useState('');
  const [touched, setTouched] = useState(false);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string>();

  const derived =
    repo
      .split('/')
      .pop()
      ?.toLowerCase()
      .replace(/[^a-z0-9-]/g, '-') ?? '';
  const slug = touched ? name : derived;
  const nameError = slug ? appNameError(slug) : undefined;
  const over = appQuotaExceeded(account as never) || !memoryAllowed(account as never, MEMORY);
  const ready =
    Boolean(repo) && Boolean(slug) && !nameError && isValidGitRef(ref) && !over && !busy;

  async function deploy() {

    setError(undefined);
    try {
      await createApp({ name: slug });

      setBusy(false);
      setError(errorMessage(err));
      return;
    }
    try {
      const dep = await deployGit({ slug, repo, ref });
      onLaunched({ slug, source: 'git', repo, ref, deploymentId: dep.id });
    } catch (err) {
      onLaunched({ slug, source: 'git', repo, ref, submitError: errorMessage(err) });

            setRepo(r);

            value={ref}
            onChange={(e) => setRef(e.target.value)}
          />

          <span className={label}>App name</span>
          <input

            className={field}
            value={slug}

              setTouched(true);
              setName(e.target.value);
            }}
          />

// src/components/canvas/launch.ts
import { deploymentPhase } from '@/lib/deployment-status';

export type LaunchStage = 'waiting' | 'queued' | 'building' | 'deploying' | 'live' | 'failed';
export type LaunchState = {
  slug: string;
  source: 'git' | 'cli';
  repo?: string;
  ref?: string;
  deploymentId?: string;
  stage: LaunchStage;
  step: 0 | 1 | 2 | 3 | 4;
  logLine?: string;
  failure?: string;
};

const DEPLOYING = new Set(['deploying', 'dispatching']);

/** Open API status → the four-step rail the node shows. */
export function launchStage(status: string | undefined): {
  stage: LaunchStage;
  step: 0 | 1 | 2 | 3 | 4;
} {
  if (!status) return { stage: 'waiting', step: 0 };
  const s = status.toLowerCase();
  const phase = deploymentPhase(s);
  if (phase === 'failed') return { stage: 'failed', step: 0 };
  if (phase === 'live') return { stage: 'live', step: 4 };
  if (DEPLOYING.has(s)) return { stage: 'deploying', step: 3 };
  if (phase === 'building') return { stage: 'building', step: 2 };
  return { stage: 'queued', step: 1 };
}

/** Watches one app's first deploy and reports it as node state. Renders nothing. */
export function LaunchTracker({
  seed,
  onChange,
}: {
  seed: LaunchSeed;
  onChange: (s: LaunchState) => void;
}) {
  const latest = useAppDeployments(seed.slug, 1, {
    pollWhileEmpty: !seed.deploymentId && !seed.submitError,
  });
  const deploymentId = seed.deploymentId ?? latest.data?.pages[0]?.items[0]?.id;
  const deployment = useDeployment(deploymentId ?? '', {
    refetchInterval: (q) =>
      deploymentId && !isDeploymentTerminal(q.state.data?.status) ? 2_000 : false,
  });
  const log = useLogStream(
    { kind: 'build', deploymentId: deploymentId ?? '', limit: 50 },
    Boolean(deploymentId)
  );
  const last = useRef('');

  useEffect(() => {
    const d = deployment.data;
    const base = {
      slug: seed.slug,
      source: seed.source,
      repo: seed.repo,
      ref: seed.ref,
      deploymentId,
    };
    const next: LaunchState =
      seed.submitError && !deploymentId
        ? {
            ...base,
            stage: 'failed',
            step: 0,
            failure: `Build was not submitted: ${seed.submitError}`,
          }
        : {
            ...base,
            ...launchStage(deploymentId ? (d?.status ?? 'queued') : undefined),
            logLine: log.lines.at(-1)?.text,
            failure:
              d && launchStage(d.status).stage === 'failed'
                ? failureSummary({ deployment: d as never }).cause
                : undefined,
          };
    const key = JSON.stringify(next);
    if (key !== last.current) {
      last.current = key;
      onChange(next);
    }
  }, [deployment.data, deploymentId, log.lines, onChange, seed]);

  return null;
}

  to: () => DOMRect | null;
  onDone: () => void;
}) {
  const reduce = useReducedMotion();
  const [el, setEl] = useState<HTMLDivElement | null>(null);

  useEffect(() => {
    if (!el) return;
    const target = to();
    if (!target) {
      onDone();
      return;
    }
    const controls = reduce
      ? animate(el, { opacity: [1, 0] }, { duration: 0.15 })
      : animate(
          el,
          {
            left: [from.left, target.left],
            top: [from.top, target.top],
            width: [from.width, target.width],
            height: [from.height, target.height],
            borderRadius: [16, 12],
            opacity: [1, 1, 0],
          },
          {
            duration: 0.6,
            ease: [0.16, 1, 0.3, 1],
            opacity: { times: [0, 0.85, 1], duration: 0.6 },
          }
        );
    void controls.then(onDone);
    return () => controls.stop();
  }, [el, from, to, onDone, reduce]);

  return createPortal(
    <div
      ref={setEl}
      data-morph=""
      aria-hidden
      className="pointer-events-none fixed z-50 border border-canvas-glass-border bg-canvas-glass shadow-elevation-3 backdrop-blur-xl"
      style={{
        left: from.left,
        top: from.top,
        width: from.width,
        height: from.height,
        borderRadius: 16,
      }}
    />,
    document.body
  );
}
```
